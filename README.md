# Bank Analytics Dashboard

## Project Overview
A banking analytics project developed to demonstrate data analysis, reporting and dashboarding skills.

## Tools Used
- Power BI
- SQL
- Microsoft Excel
- Tableau

## Project Objectives
- Analyze customer and banking performance metrics.
- Track loan approvals and repayment trends.
- Monitor revenue and other key performance indicators (KPIs).
- Present insights through interactive dashboards and visual reports.

## Key Activities
- Extracted, cleaned, validated and transformed banking data using SQL.
- Developed Power BI dashboards to monitor banking KPIs.
- Analyzed trends and performance gaps to support data-driven decisions.

## Project Deliverables
- Power BI dashboard and screenshots
- SQL scripts
- Supporting Excel analysis, where available
